## 📋 Project Overview
This repository contains the complete implementation and documentation for my PhD thesis titled: **"Analyzing Rare Disease Researches Using A Hybrid Statistical-Machine Learning Framework"**.

The research develops an **Adaptive Hybrid Regression Framework (AHRF)** that combines statistical interpretability with machine learning predictive power for analyzing imbalanced rare disease data, with Osteosarcoma (rare bone cancer) as a primary case study.

## 🎯 Research Objectives
1. Analyze limitations of classical regression models on imbalanced medical data
2. Develop AHRF framework integrating statistical and machine learning models
3. Implement advanced imbalance handling techniques (SMOTE, ADASYN, GANs)
4. Validate framework on Osteosarcoma and other rare disease datasets
5. Establish theoretical foundation for "Adaptive Imbalanced Regression"
